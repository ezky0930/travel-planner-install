설치 방법

  1. 아이폰 Safari에서 이 페이지를 열고 위 설치하기를 누르세요.
  2. "설치하시겠습니까?" 창에서 설치를 누르면 홈 화면에 앱이 생겨요.
  3. 앱을 열고 설정 탭에서 Claude API 키를 넣으면 끝이에요.

"개발자 모드가 필요합니다"가 뜨면: 설정 → 개인정보 보호 및 보안 → 개발자 모드 켜기 → 재시동.

미리 등록된 가족 아이폰에서만 설치돼요.
